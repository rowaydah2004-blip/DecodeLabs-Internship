# DecodeLabs Project 1: Data Cleaning and Preparation

## Project Overview
This project was completed as part of my Data Analytics Internship at DecodeLabs.

The objective was to prepare an e-commerce orders dataset for further analysis by examining data quality, cleaning records, and organizing the data using Microsoft Power BI and Power Query.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- Microsoft Excel

## Project Workflow
1. Imported the Excel dataset into Power BI.
2. Inspected the dataset and its columns.
3. Reviewed data types, missing values, and possible data quality issues.
4. Applied data cleaning and transformation steps in Power Query.
5. Prepared the cleaned data for further analysis.
6. Documented the workflow and saved the Power BI project.

## Project Files
- Power BI project file (.pbix): Contains the data preparation workflow.
- Project 1 PDF report: Documents the data cleaning and preparation process.

## How to Run
1. Download the Power BI project file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Select **Transform data** to inspect the Power Query steps.
4. If a refresh is needed, update the Excel source file path to the location of the dataset on your computer.
5. Select **Close & Apply** to load the prepared data.

## Outcome
The project established a data preparation workflow for the subsequent Exploratory Data Analysis (EDA) project.
